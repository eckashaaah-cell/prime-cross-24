# 模 24 素数十字与一个平滑素数和

[英文论文](paper.pdf) · [LaTeX 主文件](main.tex) · [Lean 源码](proofs/PrimeCross24.lean) · [来源与文献定位](SOURCES.md)

论文考察模 24 的八条辐条合起来究竟对黎曼的素数计数误差做了什么。冯·曼戈尔特函数只在素数幂上非零，八条之和恰好删去了 2 和 3 的正整数次幂。第 1 节逐项求和，给出在每个实数 $x\geq 1$ 都成立的恒等式。

第 2 节给出有界余项的极限分布。对于模 24，它的支撑区间约为 $[1.034388,1.242453]$。在对数尺度抽样时，落在距下端点 $s$ 以内的概率渐近于 $8.251064s$，落在距上端点 $s$ 以内的概率渐近于 $14.445066s^2$。第 3 节证明，给每个整数相同权重时，整个序列没有单一极限分布，并列出所有子列极限。

第 4 节最适合关心黎曼猜想的读者。对于公式 (1.1) 的八辐条计数误差 $E_{24}$，若 RH 成立，$E_{24}(n)/\sqrt n$ 沿整数的上极限恰为 $2+\gamma-\log(4\pi)$。若 RH 失败，上极限为正无穷，下极限为负无穷。证明用到了经典显式公式、Nicolas 对相关零点和的研究及 Landau 的振荡定理。要从十字构造独立证明 RH，还缺对全部充分大尺度成立的平方根误差估计。

第 5 节把 Alpöge 辅助素数构造中的一个同余类写成 $8M-1\pmod{16M}$。附带的 Lean 4.33.1 源码验证五条局部同余命题及调用替换证明的原引理陈述。第 1 至 4 节的解析证明写在论文中。Sutherland 网页的核验对象是 Alpöge 发布的原始工程。本仓库的修改没有整工程重编记录。
